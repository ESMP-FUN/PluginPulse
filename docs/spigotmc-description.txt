[SIZE=5][B]Your plugins stay up to date, and you decide how far it goes.[/B][/SIZE]

Most servers find out a plugin is outdated the hard way,
from a crash, a security warning, or a player telling them.

PluginPulse checks where your plugins publish their updates,
tells you when one is out, and can install it for you.
[SIZE=3][COLOR=#808080]
------------------------------
[/COLOR][/SIZE][/CENTER]
[SIZE=6][COLOR=#0000ff][B]Without it, and with it[/B][/COLOR][/SIZE]
[LIST]
[*][B]Without:[/B] you visit every plugin page to see what's new.
[B]With:[/B] one list shows what's behind.
[*][B]Without:[/B] you download, rename and copy jars by hand.
[B]With:[/B] one command, or fully automatic.
[*][B]Without:[/B] a bad download breaks your server.
[B]With:[/B] every download is checked before it's used.
[*][B]Without:[/B] a broken update means hunting for the old jar.
[B]With:[/B] [ICODE]/pluginpulse restore[/ICODE] puts it back.
[*][B]Without:[/B] you grab the wrong jar for your Minecraft version.
[B]With:[/B] the one made for your server is picked for you.
[/LIST]
[CENTER][SIZE=3][COLOR=#808080]
------------------------------
[/COLOR][/SIZE][/CENTER]
[SIZE=6][COLOR=#0000ff][B]Will it work on my server?[/B][/COLOR][/SIZE]
[LIST]
[*][B]Server software:[/B] Paper, Folia, Spigot, or a Paper fork like Purpur
[*][B]Minecraft:[/B] 1.20.5 to 1.21.x with the plain download, 26.x (including 26.3) with the [ICODE]-mc26[/ICODE] download
[*][B]Java:[/B] 21+ for 1.21.x or 25+ for 26.x
[*][B]Anything else:[/B] Nothing. No dependencies.
[/LIST]
[SPOILER="Which download do I need?"]
Minecraft 1.20.5 to 1.21.x: the plain jar.
Minecraft 26.x, including 26.3: the jar ending in [ICODE]-mc26[/ICODE].

On Spigot, notices are plain text with the link written out, instead of clickable.
[/SPOILER]

[SIZE=6][COLOR=#0000ff][B]Setup[/B][/COLOR][/SIZE]
[LIST=1]
[*]Drop the jar into [ICODE]plugins/[/ICODE] and start the server.
[*]List the plugins you want kept up to date in [ICODE]plugins/PluginPulseCompanion/config.yml[/ICODE].
[*]Run [ICODE]/pluginpulse reload[/ICODE].
[/LIST]
[CODE=yaml]plugins:
  EssentialsX:              # the name /plugins shows
    modrinth: essentialsx   # where its updates come from
    mode: notify            # tell me, download nothing[/CODE]
The plugins you list don't need to know PluginPulse exists.

More info? [URL='https://esmp-fun.github.io/PluginPulse/companion-plugin/']Read about it in the guide[/URL]

[/COLOR][/SIZE][/CENTER]
[SIZE=6][COLOR=#0000ff][B]What it does[/B][/COLOR][/SIZE]
[SPOILER="Finds updates"]
It checks Modrinth, GitHub, Hangar, a Jenkins build server, or a web address you host.
Give a plugin more than one place to check, in the order you choose.
When a plugin makes separate downloads for 1.21 and 26.x, you get the one for your server.

More info? [URL='https://esmp-fun.github.io/PluginPulse/update-sources/']Read about it in the docs[/URL]
[/SPOILER]
[SPOILER="Tells you"]
A notice in the console, and in game for anyone with [ICODE]pluginpulse.admin[/ICODE].
Click it to open the download page, or run [ICODE]/pluginpulse download[/ICODE] to install it.
[/SPOILER]
[SPOILER="Installs, only if you let it"]
Each plugin gets its own mode, from "just tell me" to fully automatic.
Every download is checked against the checksum the author published.
A damaged or tampered file is never used.
The old jar is backed up first, and the update is applied on your next restart.
[/SPOILER]
[SPOILER="Waits out brand-new releases, if you like"]
Sometimes an update is broken and fixed a few hours later.
Switch on [ICODE]hold-new-updates[/ICODE] and PluginPulse waits until a release has been out for 18 hours.
[ICODE]/pluginpulse download <plugin>[/ICODE] still installs one right away.
[/SPOILER]
[SPOILER="The modes"]
[LIST]
[*][B]off:[/B] nothing, this plugin is ignored.
[*][B]check-only:[/B] nothing, until you run [ICODE]/pluginpulse[/ICODE].
[*][B]notify[/B] (default): you're told in the console and when you join. Nothing is downloaded.
[*][B]download:[/B] it's downloaded and checked, ready for your next restart.
[*][B]auto-stage:[/B] the same as download, as soon as the update is found.
[/LIST]
[/SPOILER]
[CENTER][SIZE=3][COLOR=#808080]
------------------------------
[/COLOR][/SIZE][/CENTER]
[SIZE=6][COLOR=#0000ff][B]Commands[/B][/COLOR][/SIZE]
Every command starts with [ICODE]/pluginpulse[/ICODE] (or [ICODE]/ppc[/ICODE], [ICODE]/pulse[/ICODE]).
[LIST]
[*][ICODE]/pluginpulse[/ICODE] - every managed plugin, and whether it's up to date
[*][ICODE]/pluginpulse check [plugin|all][/ICODE] - check now
[*][ICODE]/pluginpulse download [plugin|all][/ICODE] - download the update, ready for the next restart
[*][ICODE]/pluginpulse apply [plugin|all][/ICODE] - install a downloaded update without a restart (needs [ICODE]hot-reload: true[/ICODE])
[*][ICODE]/pluginpulse restore [plugin|all][/ICODE] - go back to the previous version on the next restart
[*][ICODE]/pluginpulse reload[/ICODE] - re-read the settings file
[/LIST]
[ICODE]pluginpulse.admin[/ICODE] can use the commands and sees update notices. OPs have it by default.
[SPOILER="Settings people change"]
[CODE=yaml]plugins:
  SomePlugin:
    github: owner/repo           # or modrinth, hangar, jenkins
    mode: download
    hot-reload: false            # true = install without a restart, when it's safe
    match-server-version: true   # take the download made for your Minecraft version

user-agent-contact: "you@example.com"   # Modrinth asks for a way to reach you
check-interval-hours: 6
hold-new-updates: false          # true = wait until a release has been out a while
hold-new-updates-hours: 18[/CODE]
More info? [URL='https://esmp-fun.github.io/PluginPulse/companion-plugin/']Read about it in the guide[/URL]
[/SPOILER]

[SIZE=6][COLOR=#0000ff][B]Not running a server?[/B][/COLOR][/SIZE]
[SPOILER="Make your own plugin update itself"]
PluginPulse is also a library.
Add it to your plugin and it updates itself, with the same checks, notices and backups.
Drop a [ICODE]pluginpulse.yml[/ICODE] into your resources and call [ICODE]PluginPulse.bootstrap(this)[/ICODE], or use the builder for full control.

More info? [URL='https://esmp-fun.github.io/PluginPulse/adopting-the-library/']Read about it in the library guide[/URL]
[/SPOILER]
[SPOILER="Add updates to a jar you can't rebuild"]
Have a plugin jar but no source code?
The [URL='https://esmp-fun.github.io/PluginPulse/']browser tool[/URL] adds an updater to it.
Pick the jar, say where its updates come from, and download the new jar.
Everything happens on the page. Your jar is never uploaded.

More info? [URL='https://esmp-fun.github.io/PluginPulse/web-tool/']Read about it in the browser tool guide[/URL]
[/SPOILER]
